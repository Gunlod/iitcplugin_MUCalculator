# IITC MU Calculator

IITC上で選んだポータル、またはDraw Toolsの三角形からControl Field（CF）の推定MUを計算します。**PC・Androidとも同じ [iitc-plugin-mu-calculator.user.js](iitc-plugin-mu-calculator.user.js) をインストールします。** ビルドや追加ライブラリのインストールは不要です。

MUは外部サービスによる推定値で、Ingressの実測MUと一致する保証はありません。**「MU計算」を実行すると、各CFの3頂点座標が `https://api.investigatexm.com` に送信されます。** GUID・ポータル名は送信しません。APIキーは不要です。

## インストール

### PC：Chrome / Firefox / Edge

1. IITC-CEをインストールし、Intel Mapで動作することを確認します。
2. TampermonkeyまたはViolentmonkeyで新規スクリプトを作成し、`iitc-plugin-mu-calculator.user.js` の内容全体を貼り付けて保存します。ファイルを開いてインストールできる環境では、その方法でも構いません。
3. `https://intel.ingress.com/` を再読み込みします。
4. IITCのToolboxから **MU Calculator** を開きます。

公開URLへのホスティング・配布はこの作業には含みません。自動更新URLも設定していません。更新時は同じスクリプトを置き換えてください。

### Android：IITC-CE Mobile

1. **PCと同じファイル**を端末に保存します。
2. IITC Mobileの設定にあるプラグイン管理から、ユーザープラグインの追加・ファイル選択操作で `.user.js` を読み込み、有効にします。メニュー名はアプリのバージョン・言語で異なります。
3. Intel Mapを再読み込みし、Toolboxから **MU Calculator** を開きます。
4. PCと同じIITC標準ダイアログが開きます。「選択開始」を押し、ダイアログ外の地図で連続選択できます。必要に応じて地図を移動するか、標準の最小化操作を使ってください。

## 基本操作

1. パネルで選択モードを指定します。
2. **選択開始**を押し、地図上のポータルをクリック／タップします。A、B、Cの順に登録します。
3. 3頂点が揃うとCFを登録し、地図に半透明で描画します。
4. **MU計算**で、登録したCFを計算します。
5. パネル内のサマリーとCF一覧を確認します。

単一CFモードでは3頂点で選択を自動終了します。再び選択を開始して次のポータルを選ぶと、新しい3頂点の選択に進みます。登録済みのCFは残ります。自由選択モードでは3頂点ごとに選択を空にし、次のCFを続けて作成できます。

選択ポータルの「頂点を削除」は選択中の頂点だけを削除します。**既に登録したCFは独立したデータとして残ります。** モード変更時も選択だけを初期化します。CFを削除する場合は一覧の「CF削除」を使用してください。「全クリア」はCF・選択頂点・キャッシュを消去します。

各CFに表示切替・強調表示・色指定・削除を用意しています。非表示のCFも計算・合計の対象です。地図のLayer Chooserで **MU Calculator** 全体の表示を切り替えられます。選択・CF描画はポータル操作を遮りません。

CFをすべて削除すると、次に登録するCFの番号は **CF1** に戻ります。一部だけ削除した場合は、残っているCFの番号を維持します。

## 共通辺固定・多重CF

1. 選択モードを **共通辺固定** にします。
2. **選択開始**を押し、共通辺のA、Bを選択します。
3. C1、C2、C3…を順番に選びます。選ぶたびにA–B–Cnを登録します。固定の選択数上限はありません。
4. **選択終了**を押し、**MU計算**を実行します。

各CFのMU・面積を独立して計算して加算します。重なる面積を差し引きません。同じ3頂点は順序が異なっても重複登録しません。GUIDとAPIと同じ小数6桁の座標で重複を判定します。

一部失敗・未計算・キャンセルがある場合は **成功分小計** と表示します。失敗を0 MUの成功として扱いません。APIが正常に返した0 MUは成功として扱います。登録CF枚数は最大重複レイヤー数ではありません。最大レイヤー数の推測値は表示しません。重なりは半透明の色とCFごとの強調で確認してください。

全CFが成立すると仮定した推定値です。リンクの構築順序、CFの成立可否、既存リンクとの干渉は検証しません。

## Draw Tools連携

Draw Toolsを有効にし、MU Calculatorの **Draw Toolsから取り込み** 欄で選択します。

| 操作 | 対象 |
|---|---|
| 三角形Polygon | 3頂点のPolygon。始点と終点が同じ閉じたリングも対応 |
| リンクから検出 | Polylineの明示的な3辺が閉じる三角形 |
| 両方 | 上記をまとめて検出し、重複を除去 |

検出後に「追加可能」「登録済み」「対象外・無効図形」「候補内重複」の数を表示します。**確認して登録**で取り込みます。解析・登録の途中は「キャンセル」で中止できます。登録途中のキャンセルでは、それまでに登録したCFが残ります。

四角形以上・穴のあるPolygon・複雑な複数リングは取り込みません。自動三角形分割はしません。Polylineに明示された連続頂点間を辺として扱います。線の交差点や途中に重なる座標を、新たな頂点として追加・分割しません。座標一致はAPIと同じ小数6桁の正規化を使います。丸めの境界を跨ぐ点は別頂点です。

現在読み込まれているポータルと座標が一致すればGUIDと名前を補完し、一致しなければ座標だけで計算します。**Draw Toolsの図形は、ポータルの実在やリンク構築可能性を保証しません。** Draw Toolsのレイヤー・保存データを変更せず、別のMU Calculatorレイヤーで管理します。Draw Tools未導入の場合も直接選択は利用できます。

## 保存・CSV・JSON

選択モード、頂点、CF、CFの色と表示状態、強調状態、計算キャッシュをIntel MapのlocalStorageに保存します。選択中フラグと通信中ジョブは復元しません。ページを閉じると通信をキャンセルします。通常は変更から250ms後に保存し、ページ離脱時にも保存します。端末間での自動同期はありません。

**CSV出力**はUTF-8 BOM付きで、CF番号・頂点名・各緯度経度・MU・面積・状態・モデル・計算日時・エラーを含みます。CSVの数式として実行される可能性がある先頭文字はアポストロフィで保護します。座標の負数も保護対象なので、Excelで必要に応じて数値に変換してください。

**JSON出力**はスキーマバージョン、ポータル情報、座標、計算結果、モデル、計算日時、表示設定、キャッシュを含みます。**JSONインポート**からファイル選択またはテキスト貼り付けで読み込めます。確認後に現在の計画を置き換えます。読み込みデータが不正なら置き換えません。

AndroidではIITCの公式エクスポート機能を使用し、対応する環境ではネイティブの保存画面を開きます。旧IITCでは `app.saveFile` / `saveFile`、通常ブラウザではBlobのダウンロードに対応します。

保存済み・インポートしたMUは最初は **モデル未確認／参考値** と表示し、合計に含めません。**MU計算**を押すと `/health` で現在のモデルを確認し、一致するキャッシュだけを利用します。モデルを確認できなければ新しく計算します。計算中に異なるモデルが混在した場合は合計に含めず、再計算を案内します。

## API制限とエラー

利用APIは [MU Calculator公式仕様](https://mu.investigatexm.com/api.html) です。

| 項目 | 処理 |
|---|---|
| 単一CF | `POST /getMU` |
| 複数CF | `POST /getMUbulk`、最大50 CFずつ順次送信 |
| リクエストサイズ | UTF-8 JSONで32,768バイト以内に分割 |
| サーバー処理時間 | 1リクエスト20秒。未完了CFは失敗になる場合あり |
| クライアント待機時間 | 25秒で中断。通信遅延分の余裕を含む |
| 座標 | 緯度±90、経度±180、6桁のhalf-up丸め。重複頂点・面積ゼロ・対蹠辺を拒否 |
| 通信方式 | fetch＋AbortController。未対応環境はXMLHttpRequest |

通信はCORSの許可に従います。GM権限や独自ネイティブ通信ブリッジは要求しません。ブラウザで禁止されるUser-Agentヘッダーは設定しません。キャンセルは以降の送信とローカル待機を止めますが、既にサーバーに届いた処理を必ず止められるわけではありません。

HTTPエラー、タイムアウト、CORS・ネットワーク障害、非JSON応答、bulkの `ok:false`、欠落・不正なMU・面積・モデル・座標を識別します。失敗CFを確認して「MU計算」を再実行してください。成功分はモデルが一致すればキャッシュを利用します。

## スマートフォンの操作

PC・スマートフォンとも、MoreFieldsと同じ基本的な `dialog({html,id,title,width:'auto'})` で開きます。タイトルバー・最小化・閉じるボタン・配置はIITC標準の動作に任せ、独自ボタンや位置指定CSSは追加しません。パネル内の操作ボタンは44px以上を確保し、長い一覧のスクロール、CF・選択頂点の50件単位のページ送りに対応します。「選択開始」時に地図画面へ切り替え、各ポータル選択では切り替えません。通常のIITCポータル詳細イベントを置き換えません。

パネルは選択中も表示したままです。選択を止める場合は **選択終了** を利用してください。標準の **×** や **OK** で閉じると選択を終了し、登録CFと計算結果は保持します。Toolboxの **MU Calculator** から開き直せます。最小化・復元、Escape、Androidの戻るボタンもIITC標準の動作に従います。ページ離脱時には選択を終了し保存します。ネイティブの戻る動作・画面回転を含む実機検証は未実施です。

## トラブルシューティング

| 症状 | 確認事項 |
|---|---|
| Toolboxに表示されない | IITC・本スクリプトを有効にしてIntel Mapを再読み込み。旧版との二重導入を避ける |
| ポータルが追加されない | 「選択開始」後にポータル本体を選択。未読み込みポータルや選択済み頂点は追加されない |
| 同じ辺のCFが増えない | A・B・Cが球面上で面積ゼロ、丸め後に同一、または同じCFを登録済みでないか確認 |
| Draw Toolsが無効 | Draw Toolsを有効にして再読み込み。取り込み対象の図形を作成する |
| HTTP 403 / 非JSON | APIのCDN・アクセス制限の場合あり。時間を置くか別の回線で再試行 |
| タイムアウト・deadline exceeded | CFごとの失敗欄を確認して再試行。API側の混雑や大きいCFの処理時間が原因の場合あり |
| CORS・ネットワーク | 回線・端末WebView更新・拡張機能の通信遮断・APIの稼働状況を確認 |
| 保存できない | localStorageの容量・制限を確認し、JSON出力でバックアップ |
| 合計が小計、またはMUが参考値 | 未計算・失敗・キャンセル・モデル未確認のCFがある。「MU計算」で確認・再計算 |
